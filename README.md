# Job Application Tracker

A lightweight web app for tracking internship and job applications in one centralized, easy-to-use interface.

This project focuses on clarity, usability, and realistic product constraints rather than backend complexity.

**Check it out here:** [https://britneylu.github.io/job-app-tracker/](https://britneylu.github.io/job-app-tracker/)

---

## Features

- Track applications by company, role, status, and dates  
- Filter and search across all applications  
- Automatic follow-up reminders with overdue indicators  
- Compact ⋯ action menu for edit, duplicate, and delete  
- Local data persistence using `localStorage`  
- Import and export application data (JSON)  
- Responsive design for desktop and mobile
